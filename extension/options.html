安装 / 排障
README

    

      
    
        
  • DSH 侧需要安装 @sssonamuuu/dsh-browser-bridge 插件，扩展才能找到本地桥。
    • 
        
  • 默认不会 attach debugger；只有在 DSH 输入框用 @ 选择标签页后才会 attach，浏览器会显示“正在调试此浏览器”提示。
    • 
        
  • Chrome 用 chrome://extensions，Edge 用 edge://extensions，打开开发者模式，加载本仓库的 extension/ 目录。
    • 
        
  • 同一个扩展目录可以同时被 Chrome / Edge / Brave 加载，不需要改代码。
    • 
        
  • “检测端口”会扫描 47821-47830，显示找到的 bridge 版本和是否允许配对。
    • 
        
  • 工具读不到 console/network 时：确认扩展是在页面加载前就启用，或刷新页面后重新触发。
    • 
        
  • 截图只截当前可见视口；点击是 DOM 级事件，不是 trusted input。
    • 
        
  • 完整文档见仓库 docs/INSTALL.md 和 docs/TESTING.md。
    • 
      

    

  


  
数据只在本机 127.0.0.1 上传输。扩展拥有读取所有站点的权限，请只安装在你信任的浏览器 profile 中。
